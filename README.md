# local_ai_transalator
python translator script with GUI that runs locally using gemma3 model or any other model u want to use.

#Script 1 : main.py
FEATURES : 
->Uses llama_cpp, pytorch for ocr, streamlit for gui
->Translates text, images, files (txt, pdf, docx, xlsx, ppt)
->Designed for gemma-3-12b-it-Q3_K_L.gguf but will work for any model with some tweaks
->Chat mode for interactions

#Script 2 : main2.py
FEATURES : 
->Uses ollama, nicegui for gui
->Translates text, files
->Chat mode for interactions
